01 / HOW IT WORKS

Different paths.
One standard: does it work?

More answers don’t make an answer true. Mycelium checks results against the task—not against a majority vote.

  1. 01 →

    Set the goal

    Define success, permissions, and a fixed resource budget before work begins.

  2. 02 →

    Explore different ways

    Workers try distinct strategies independently. Checked partial results can help later attempts.

  3. 03 →

    Verify the result

    Use trusted checks or real outcome evidence. Missing evidence stays inconclusive.

  4. 04 →

    Test what was learned

    Turn recurring gaps into candidates. Keep a change only after fresh tests and release approval.

What actually runs on each worker?+

MVP3 uses qualified full-model replicas for asynchronous, bounded work. Each replica serves the same complete model; different strategies change how a task is approached. This is not token-level expert routing, and the replicas do not pool GPU memory.

The offline pilot uses a symbolic worker. Model transport is tested with local HTTP fixtures; useful live pretrained-model performance and a large volunteer network are still unproven.

What happens if a worker disappears?+

A healthy, compatible replica can take new work. But if a request was already sent and its outcome is unknown, MVP3 does not blindly retry it elsewhere. That job stays inconclusive and its resource reservation is preserved.

Recoverable job records, checkpoints, and retained release artifacts help a trusted coordinator resume safely. They are not proof of geographic high availability, physical outage recovery, or hostile-volunteer isolation.

04 / THE EVIDENCE SO FAR

Small proofs.
Honest conclusions.

MVP3 tests the learning loop and its safeguards. The ambition is broad; the demonstrated scope is deliberately narrow.

DEMONSTRATED

A tested skill filled a specific gap.

The symbolic arithmetic demo improved after adding a transparent bootstrap recipe. This shows the mechanism—not a learned LLM capability gain.

Frozen software checks

1,204 passed · 12 inherited skips. A separate independent MVP3 review passed 238 tests. These overlap with the aggregate; they are not additional wins or intelligence scores.

Runtime frozen 27 October 2026. Local HTTP fixtures exercise transport and proposal paths, not live pretrained-model quality.

What the small demo measured

The symbolic worker went from 4/6 to 6/6 on both fixed fresh and regression samples using a handwritten bootstrap skill. No useful policy-only gain was measured. This is not statistical evidence of generalization.

The connected tiny-weight run rejected all three candidates. Docker goal execution, a live pretrained endpoint, and live platform outcomes were unavailable in this campaign.

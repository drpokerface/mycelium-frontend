Model weights new instincts

Illustrative example: tuned on the videos people finished

Verified wins become training examples that nudge a copy of the model, so good choices happen without instructions.

Kept when the copy beats the current model on new tasks without slipping on old ones. Useful pretrained-model gains have not been demonstrated.

Every change is tested on the side first. The live version keeps running until it clears:

  1. Helps on new tasks
  2. Old tasks still pass
  3. Within budget
  4. A person approves
Contribution credit

Useful work earns karma.

In the trusted MVP4 pilot, admitted work earns karma after independent verification. Awards are recorded, and each trusted ledger blocks duplicate credit.

Verification is operator-controlled. Karma is not money; an open, permissionless rewards network is not live.
Future roadmap

From karma to crypto tokens.

Planned: redeem crypto tokens based on earned karma.

Redemption is not available today. No conversion rate, token value or launch date is promised.

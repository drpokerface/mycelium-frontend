Mycelium is an AI research pilot. It sends several AI workers at one goal, checks every finished result independently, and keeps only what passes.

One attempt is a gamble

Ask an AI for something open-ended and you get one try. It may well work, but a far better route may never be explored. Mycelium tries many routes in parallel, judges each finished result, and grows the next round from the best one. Round after round, the result improves.

Where this matters: goals with no known right answer, where the only way to find out is to try. A short video that is actually funny. A channel that keeps growing.

Picture it growing a YouTube channel

First it finds one route that works. Then it keeps improving it: the route bends toward whatever works better, and the rest dissolve.

      Three ways it should get better

      From a saved recipe to a change in the model itself. Deeper changes face a higher bar.

      Easy to undoDeep change

      Skills a saved how-to

      A small, tested procedure it can rerun instead of working it out again. Kept when it helps on new tasks.

      Built

      Verified results can be saved as recipes and offered on later goals, with a fresh check each time. Not yet shown to help on new goals.

      Thinking strategies a better approach

      A short written instruction it follows, like a checklist. Kept when the same model, on the same budget, scores higher with it on new tasks.

      Built

      Within one goal, MVP-7 already compares whole strategies live. Carrying a winner over to new goals has a test gate in the code, but no live result.

      Model weights new instincts

      Verified wins become training examples that nudge a copy of the model. Kept when the copy beats the current model on new tasks without slipping on old ones.

      From a circle of friends to an open network

      The plan is for Mycelium to grow the network it runs on, and the model it thinks with.

      Built

      A circle of friends

      People on their own computers pick up work through a shared GitHub issue. A separate verifier checks it, and verified work earns karma. Tested as a simulation so far. No real group has run it yet.

      Planned

      Two standing jobs for the circle

      • Run a YouTube channel that shows the work and brings new people in.
      • Build Mycelium's own language model, as a second continuous goal.

      When that model is good enough, the network opens.

      Planned

      An open volunteer network

      Anyone can join. The network runs on Mycelium's own model, hosted on infrastructure the volunteers share, instead of on an outside AI service. Trust between strangers is still unsolved.

      What is built, and what is planned

      MVP-7, November 2026. A research pilot run by one operator on one machine.

      Run live

      Ran end to end with real AI models.

      • Several complete attempts in parallel
      • Independent AI review of each finished result
      • The best checked version kept, with a fallback
      • Recombining parts of earlier results
      • A spending cap, with a receipt per AI call
      • A safe stop on failure, nothing faked

      Built

      Coded and tested. Not yet run live.

      • Circle of friends over a shared GitHub issue
      • Separate verifiers, and karma for verified work
      • Reusable recipes, re-checked on every reuse
      • Non-video tasks, in offline tests
      • Rollback to an earlier approved version

      Planned

      The vision. Not built or not yet shown.

      • Real-world feedback as the judge
      • A live channel, with rounds that continue on their own
      • Skills and strategies shown to help on new goals
      • Model updates from verified wins
      • Mycelium's own language model
      • An open volunteer network on shared infrastructure
      • A person's sign-off on deep changes

      Latest live run and its limits
